Sub2API 0.6.1

相对 v0.6.0，本版只更新用户门户前端：新增配色风格选择，调整表格页布局，并简化首页与模型监控页。

## 用户门户

- 顶栏、首页和登录页的深浅切换改为「配色风格」选择，内置 11 套：素白、夜色、深灰，以及参照 Claude、OpenAI、Gemini（各有浅／深）、Grok（深）、DeepSeek（浅）品牌主色的配色。只使用颜色，不含各厂商的标识。浏览器会记住所选风格；通过上游的深浅切换时，切到该模式上次使用的风格。
- 深色风格下像素图标改为实心中间调，修复只剩亮线框、显示发虚的问题。
- API Key、用量、订单、可用渠道等表格页铺满视口宽度，表格随每页条数增高，不再在一屏内滚动；其余页面保持原宽度。
- API Key 页删除顶部统计栏（总数、启用、本月花费、7 天内过期）。
- 首页取消约 3 秒的入场动画和「重播入场」按钮。
- 模型监控页的状态色块不再显示悬停提示，相同信息保留给读屏软件。
- 已打开的图表在切换配色风格后跟随新配色。

## 数据库迁移

无。本版只改前端，后端代码与迁移文件与 v0.6.0 相同。可直接替换镜像，也可回退到 v0.6.0；升级前仍建议备份 PostgreSQL 和 /app/data。
