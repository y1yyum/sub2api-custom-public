Sub2API 0.5.1

管理端调用日志增加流式响应诊断，帮助识别上游用量缩放和流完整性。

## 变更

- 原 token 单元格增加缩放、输入用量变化率、结束原因和完整性小标记。
- 诊断详情显示初始／最终上游声明用量、服务档位、工具与推理轮次等有限摘要；缺失值保持未知。
- 仅管理员 API 和界面可见；用户端暂不显示。
- 复用原转发观察器和用量写入，不新增上游请求，不保存正文、工具参数或原始 SSE。

本版本仅从本地开发仓库选择性移植本次诊断功能，未同步其他本地改动。
上游声明用量（包括初始值）可能已被缩放，不能据此反推出真实 token。

## 数据库迁移

新增 `9010_usage_response_diagnostics.sql`：在 `usage_logs` 增加可空
`response_diagnostics JSONB`，无默认值、回填或新索引，不修改或删除已有数据。
旧行保持 NULL，旧镜像可忽略新增列，允许回滚旧镜像并保留该列。
部署前备份数据库；DDL 需要短暂表锁。生产升级结果为 Unknown，本次发布不执行部署。
