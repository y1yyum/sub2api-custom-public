Sub2API 0.6.0

相对 v0.5.2，本版更新用户门户和管理端智力检测，并加入默认关闭的网关桥接与独立调度试点。保留已发布的用量诊断和图片题库功能。

## 用户与管理员

- 更新登录、概览、API Key、用量和钱包页面，改进筛选、表格与加载／空状态。
- 管理端可在智力检测页面集中管理检测计划和题库，按账号查看计划；保留 v0.5.2 的已保存题图和失败处理规则。
- 注册邮箱可按完整地址阻止注册；管理员可选择批量停用已命中的用户。用量 CSV 导出分页，遇到限流时按 Retry-After 重试。
- OpenAI 生图请求支持按 1K／2K／4K 尺寸选择账号；Kimi 并发上限 403 使用短冷却。

## 网关试点

- Core 增加受信桥接入口、固定账号转发、用量回执和遥测。独立 Edge／调度工具支持影子选号，以及显式启用的受限严格选号；Core 的原生资格检查仍为最终否决。
- 调度支持加权轮询、在途负载、按范围隔离故障、质量评分与拥堵延期、探针金额上界、带版本的快照订阅、硬失效通知和聚合指标。定时任务可显式迁移执行方。
- 常规镜像和平台归档的主程序仍是 sub2api；独立 Edge、调度及迁移工具随源码提供，不会随镜像启动。尚未完成网关整体 E2E、容量或生产迁移验收；本版不包含 M3 团队预算与客户账本。

## 数据库迁移

- **公开发行包的常规 Core 升级：无新增自动 SQL 迁移。** 公开 v0.5.2 的迁移（含 9010 用量诊断、9011 图片题库）按原文件保留。升级前备份 PostgreSQL 和 /app/data；常规升级无需迁移或重签用户 Key。
- **可选网关：** Edge 本身不使用数据库；Core 侧回执／遥测、独立影子接收库和调度库按各自入口配置，不能把所有扩展 SQL 一并施加在 Core 库上。只有显式执行相应管理命令时才应用扩展 SQL。桥接使用 backend/internal/custombridge/migrations/ 下的 001_receipt_outbox、002_receipt_delivery、003_shadow_inbox、004_forward_attempt、005_telemetry、006_telemetry_ttft、007_telemetry_failure、008_telemetry_timeout、009_telemetry_protocol（均为 .sql）。调度使用 backend/internal/custom/dispatch/migrations/ 下的 001_dispatch、002_quality（独立入口）、003_failure_holds、004_probe_budget、005_publish_lineage、006_metrics_retention（均为 .sql）；定时任务执行方使用 backend/internal/custom/scheduledowner/schema.sql。按实际启用范围备份相关数据库，不在常规升级时统一执行这些文件。
- 未启用试点可回退旧镜像；启用过试点时先停止新准入，排空在途请求和待交付回执；已迁移定时任务须按冻结、排空、交还原执行方的顺序回退，保留账本和审计数据。生产升级及回退未经本次发布验证。
